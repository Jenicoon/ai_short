# 사람들은 왜 AI 숏드라마에 열광하는가?

한양대학교 「중국미디어문화의이해」 3조 **「본 조는 AI로 생성되었습니다」**의 온라인 전시 사이트입니다.
중국 AI 숏드라마의 인기 요인과 문화적 의미를, 기준작 《一双手闯出一片天》과 비교작 4편을 따라가며 보여 줍니다.

- 최아령 (조장): A4 연구 원고
- 위명현: 근거 수집
- 이승하: 온라인 전시
- 김민경: 1분 콘텐츠

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈 (전시 입구, 전시실 목록) |
| `research.html` | 연구: 현상과 질문 |
| `works.html` | 작품: 기준작 《一双手闯出一片天》과 상영관 |
| `analysis.html` | 분석: 비교작 4편, 분석 축 4개 (서사 구조, 소재와 배경, 인물 이미지, 볼거리) |
| `evidence.html` | 근거: 외부 근거, 맥락과 반론, 결론 |
| `quiz.html` | 테스트: 나에게 어울리는 숏드라마는? |
| `about.html` | 소개: 발표 아카이브, 만든 사람들, 출처 |
| `css/style.css` | 디자인 (라이트/다크 테마, 반응형) |
| `js/nav.js` | 모든 페이지 공통 상단 메뉴와 바닥글, 테마 전환 |
| `js/main.js` | 장면 타임라인, 차트, 비교 기록표, 상영관, 슬라이드, 라이트박스 |
| `js/quiz.js` | 심리테스트 「나에게 어울리는 숏드라마는?」 |
| `js/data.js` | `data/comparison.json`과 같은 데이터 (로컬에서 파일로 열어도 차트가 그려지도록) |
| `data/comparison.json` | 작품 비교 관찰 데이터 원본 |
| `assets/` | 이미지, 영상, 발표 슬라이드 |

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 열면 바로 보입니다.
(상영관의 YouTube 클립은 `file://`로 열면 재생이 막힐 수 있으니, 배포 후나 로컬 서버에서 확인하세요.)

## GitHub Pages로 배포하기

1. 이 폴더의 내용을 GitHub 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 지정합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

`comparison.json`을 고치면 `js/data.js`도 같은 내용으로 맞춰 주세요.
